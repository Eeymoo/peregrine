# v0.2.1 发布测试计划

> 本文档面向 **v0.2.1 稳定版发布**（当前分支 `feature/four-layer-customization`，版本号 `0.2.1（待 bump）`）。
> 它回答两个问题：**发版前必须测什么**、**按什么顺序测**。
> 功能级逐项勾选清单见 `docs/manual-test-checklist.md`（A–H 区），本文档只定义测试范围、流程、门禁与放行标准，不复述其中的条目细节。

---

## 1. 测试范围（v0.2.1 相对 v0.1.16（最新稳定版）的增量）

| # | 模块 | 变更摘要 | 风险等级 | 对应清单区 |
|---|------|----------|----------|-----------|
| S1 | 四层架构 | Element / Material(Rhai) / Layer / Profile 全链路重构 | **高** | B、D |
| S2 | 物料运行时 | 静态渲染启用；**动态输入软禁用**（`MATERIAL_DYNAMIC_INPUT_ENABLED=false`） | **高** | D、H |
| S3 | 配置迁移 | 旧 `crosshair` 配置自动迁移为 `layers`，备份 `.legacy.bak` | **高** | B1、D4 |
| S4 | 多 Profile | 新建/重命名/复制/删除/切换，单双图层模式记忆 | 中高 | A |
| S5 | 匿名遥测 | GlitchTip 接入、首次授权、panic 落盘回传、install_id、脱敏、开发者模式 | **高（隐私）** | E、F |
| S6 | 前端重构 | 组件拆分、统一字段控件（12 种样式）、单/多图层编辑器 | 中 | G |
| S7 | dev 功能合并 | 单例模式、Markdown 更新日志、镜像下载修复 | 中 | C |
| S8 | 近期修复回归 | 单图层编辑滞后一帧（`38cb42c`）、预览滞后一次（`d97a03d`）、遥测关键路径接线（`e4c9a25`） | 中 | §4.4 |

非目标：用户自定义物料（B3 区，当前仅内置物料）、动态物料效果（B4/H 原语义，已软禁用）、Linux/macOS 运行（仅编译通过即可）。

## 2. 测试环境矩阵

| 环境 | 用途 | 必需 |
|------|------|------|
| CI（ci.yml） | 自动化门禁：3 crate 测试 / clippy / fmt / 前端构建 | ✅ |
| Windows x86_64 实机 | 全部人工验收的主环境（含游戏窗口跟随） | ✅ |

| GlitchTip TEST / 正式项目 | 遥测事件核对 | ✅ |
| 旧版 v0.1.x 用户配置样本 | 迁移测试 | ✅ |

## 3. 测试流程与门禁（按顺序执行，前一阶段不过不放行）

### 阶段 0：自动化门禁（CI / 本地）

- [ ] 0.1 `cargo test`（config / material / peregrine 三 crate）全部通过
- [ ] 0.2 `cargo fmt --check` + `cargo clippy -- -D warnings`（3 crate）通过
- [ ] 0.3 `npm run build`（含 `tsc` 类型检查）通过
- [ ] 0.4 CI 四个 job 全绿（build / test-report / frontend-report / lint → quality-gate）
- [ ] 0.5 快照构建成功：`gh workflow run snapshot.yml --ref <branch>`，三架构产物产出

### 阶段 1：功能验收（快照包，Windows 实机）

执行 `docs/manual-test-checklist.md` 全部适用区，放行标准：

- [ ] 1.1 A 区（多 Profile）：全部通过，含 2026-08-04 已修复项的回归（A1.6 快捷色即时生效、A2.4 上移/下移方向、A2.6 禁用态样式一致、图层删除 `layer not found` 不再复现）
- [ ] 1.2 D 区（静态多图层渲染）：D1 / D2 / D3 / D5 全部通过；D4（旧配置兼容）转入阶段 2 必测
- [ ] 1.3 G 区（12 种样式字段控件）：单图层 12 样式全部复核，双向同步、ColorField 非法值兜底通过
- [ ] 1.4 C 区（单例 / 更新日志 / 镜像）：通过
- [ ] 1.5 E 区（开发者模式门禁）：**重点 E2**，release/快照构建默认 5 Tab、右键无「检查」、连点 5 次解锁、重开窗口后 DevTools 可用
- [ ] 1.6 H 区（动态停用语义）：H1 长跑 30 分钟 CPU 无空转；H3 serde 兼容通过

### 阶段 2：迁移与兼容（**发布阻断项**）

v0.2.1 的最大用户风险是旧配置被改坏。必须用真实样本验证：

- [ ] 2.1 备份真实用户 `%APPDATA%\Peregrine\config.json`，用 v0.1.16 各内置样式（至少 cross / ring / edge_rect / corner_dots / border_frame / edge_arrows / grid）各生成一份旧配置 → 升级到 v0.2.1 → **视觉零退化**（截图对比）
- [ ] 2.2 迁移后备份文件 `config.json.legacy.bak` 存在且内容完整
- [ ] 2.3 迁移后在新版继续编辑保存 → `layers` 数据完整、不降级回旧格式
- [ ] 2.4 损坏 JSON / 非法值配置 → 回退默认配置并备份 `.bak`，应用正常启动
- [ ] 2.5 纯旧配置（无 `layers` 字段）渲染外观与 v0.1.16 完全一致（D4.1）
- [ ] 2.6 自定义 PNG 图片配置迁移后可用（`custom_image` 若仍处于隐藏状态，需明确发版说明；若恢复则纳入 2.1 对比）

### 阶段 3：遥测与隐私（**发布阻断项**，快照包 + GlitchTip 核对）

执行清单 F 区全部条目，发版门禁特别核对：

- [ ] 3.1 首次授权弹窗**只弹一次**（F4），此后任何状态切换不再弹
- [ ] 3.2 开关关闭 / 无 DSN / `PEREGRINE_DISABLE_TELEMETRY` 编译 → **零出站网络请求**（抓包，F2）
- [ ] 3.3 panic 落盘 → 静默回传 → 清除（F3 全组）
- [ ] 3.4 install_id 稳定性与重建（F5）
- [ ] 3.5 事件脱敏抽样：无 IP / 用户名 / 机器名，路径 `{user}` 替换（F6，中文用户名账户必测）
- [ ] 3.6 DSN 未入库：`git log -p --all | grep -E "GLITCHTIP_DSN|VITE_GLITCHTIP"` 仅出现变量名
- [ ] 3.7 所有事件携带 `code` tag，`event_type` 三类可筛（F1.4 / F1.2）
- [ ] 3.8 遥测关键路径接线回归（`e4c9a25`）：人为制造一次配置保存失败（如 config 目录只读）→ GlitchTip 收到 `PGR-2101`，且应用**维持原有降级行为不崩溃**

### 阶段 4：近期修复专项回归（最近三个 fix 提交，清单未覆盖）

## 4. 放行标准（Definition of Done）

1. 阶段 0–3 全部通过（阶段 2、3 为**阻断项**，任一失败不得发布）。
2. 阶段 4–5 全部通过；性能超标须另开修复 change，不带病发布。
3. 阶段 6 在正式 tag 构建上全部通过（6.4 允许先用预发布 tag 演练）。
4. 文档与归档完成（阶段 7）。
5. 发布后 48 小时观察 GlitchTip 正式项目：无集中爆发的新 issue、crash 率无异常抬升。

## 5. 已明确「不测/跳过」清单（避免反复评估）

- B3 用户物料错误隔离：仅内置物料，跳过（保留物料运行时自身鲁棒性，已由单测覆盖）
- B4 / H 原动态语义：`MATERIAL_DYNAMIC_INPUT_ENABLED=false`，动态效果不测；翻回开关时重新启用该清单
- `multi-profile-config` 遗留「多图层模式管理 profile」：物料运行时软关闭期间曾不可达，现静态渲染已恢复，**并入 A 区正常验收**，不再暂缓
