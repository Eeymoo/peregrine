## 通用

![通用设置](/img/screenshots/settings-general.png)

| 设置项 | 对应字段 | 默认值 | 生效方式 |
|--------|----------|--------|----------|
| 语言 | `settings.locale` | `auto` | 即时 |
| GPU 加速 | `settings.gpu_acceleration` | 关闭 | 需重启 |
| 遥测 | `settings.telemetry_enabled` | 未授权 | 需重启 |

- **语言**：`auto` 跟随系统语言，也可固定为简体中文 / English 等选项。切换到非简体中文时，中国大陆镜像加速会被自动关闭。
- **GPU 加速**：控制设置窗口 WebView2 的硬件加速。默认关闭可将 GPU 进程内存从约 80MB 降到约 15MB；界面卡顿时可尝试开启。切换后程序会询问是否立即重启。
- **遥测**：匿名崩溃上报 + 启动统计的授权开关（详见[隐私与遥测](./privacy.md)）。变更需重启后生效，选择「稍后重启」时会显示待重启标记。若构建时未注入 DSN（如自行编译），此项整体隐藏。

## 覆盖层

![覆盖层设置](/img/screenshots/settings-overlay.png)

| 设置项 | 对应字段 | 默认值 | 生效方式 |
|--------|----------|--------|----------|
| 开始覆盖时 | `settings.auto_switch_on_overlay` | `ask` | 即时 |
| 拖拽时实时显示 | `settings.live_drag_preview` | 关闭 | 即时 |
| 抗锯齿 | `settings.antialiasing` | 开启 | 即时 |
| 渲染后端 | `settings.renderer_backend` | `cpu` | 即时 |
| 快捷颜色 | `settings.quick_colors` | 白绿蓝红橙 | 即时 |

- **开始覆盖时**：控制点击「开始覆盖」后配置窗口的行为——`询问` 每次弹窗确认、`自动切换` 直接隐藏配置窗口并切到目标窗口、`保持显示` 不做处理。
- **拖拽时实时显示**：仅窗口模式（非全屏覆盖）生效。关闭时拖拽窗口期间隐藏准心、停止拖拽约 1.2 秒后恢复，避免拖拽跟手产生的晃动；开启则全程可见。
- **抗锯齿**：开启后圆、圆环、三角形等曲线边缘更平滑；低性能设备可关闭以略微降低 CPU 开销。
- **渲染后端**：两种后端的行为对比：

| | CPU（默认） | SVG |
|---|---|---|
| 实现 | 手写 CPU 像素光栅化 | 图元转 SVG，由 resvg / tiny-skia 光栅化 |
| 抗锯齿质量 | 一般（需配合抗锯齿开关） | 更高 |
| 依赖 | 零额外依赖 | 随内置 SVG 后端引入 |
| 适用 | 绝大多数场景 | 对曲线边缘质量敏感时 |

- **快捷颜色**：5 个可自定义的颜色预设。点击色块打开取色器修改；配置页中点击色块即可一键切换准星颜色，也可用快捷键循环 / 直接选择（见下文[快捷键](#快捷键)）。可一键恢复默认（白绿蓝红橙）。

图层的增删与参数编辑在配置窗口的多图层编辑器中进行，参见[图层管理](./layers.md)。

## 物料

![物料设置](/img/screenshots/settings-material.png)

| 设置项 | 对应字段 | 默认值 | 生效方式 |
|--------|----------|--------|----------|
| 动态物料 | `settings.material.dynamic_enabled` | 开启 | 即时（热生效） |
| 动画帧率 | `settings.material.fps` | 跟随系统 | 即时（热生效） |

### 动态物料两层与门

「动态物料」指依赖运行时输入（时间、鼠标位置、按键状态等）实时变化的物料（如 `builtin.time` 时钟）。动态链路是否活跃由**两层开关取与（AND）**决定：

<Mermaid
  chart={`graph LR
    A["编译期总闸<br/>MATERIAL_DYNAMIC_INPUT_ENABLED"] --> AND{"AND"}
    B["运行时用户开关<br/>dynamic_enabled"] --> AND
    AND -->|"两者均为真"| C["动态链路活跃<br/>输入轮询 / 动态求值上下文 /<br/>连续重绘 / 选择器动态物料可见"]`}
/>

- **两者都开**（正式版默认状态）：动态物料按帧率节拍连续重绘。
- **运行时开关关闭**：用户侧软关闭——动态物料改用静态上下文求值（冻结在某一帧），热生效、无需重启；输入轮询与周期性唤醒停止。
- **编译期总闸关闭**（特殊构建）：整个「物料」Tab 隐藏，运行时开关无消费方。

### 动画帧率（FPS）语义

| 档位 | 语义 |
|------|------|
| 跟随系统 | 跟随主屏刷新率（探测失败回退 60） |
| 30 / 60 / 120 | 固定帧率上限（cap），校验仅接受这三个值 |

FPS 是**动画最高帧率节拍**而非强制帧率：只有包含动态物料的 profile 才会按节拍周期性重绘；**纯静态 profile 保持事件驱动、不受任何影响**。修改 FPS 立即热生效，无需重启。

物料脚本（Rhai）的编写参见[物料脚本创作](./material-scripting.md)。

## 快捷键

![快捷键设置](/img/screenshots/settings-hotkeys.png)

可绑定的动作与默认键位：

| 动作 | 说明 | 默认键位 |
|------|------|----------|
| `toggle_overlay` | 切换覆盖层显示 / 隐藏 | `Ctrl+Alt+O` |
| `start_overlay` | 开启覆盖层 | 未绑定 |
| `stop_overlay` | 关闭覆盖层 | 未绑定 |
| `cycle_color_next` / `cycle_color_prev` | 循环切换快捷颜色预设 | 未绑定 |
| `set_color_1` ~ `set_color_5` | 直接选用快捷颜色 1~5 | 未绑定 |

**录制交互**：点击某行的键位框进入录制态（边框高亮、提示「按下组合键…」），按下 `Ctrl` / `Shift` / `Alt` / `Super` 修饰键 + 主键即完成绑定（纯单键不可绑定，避免误触）；按 `Esc` 清除该行绑定。同一键位不可重复绑定——新绑定会自动移除其他动作上的相同键位。变更即时保存。

## 更新

「更新」Tab 提供手动「检查更新」按钮与两项偏好：

- **更新通道**（`settings.update_channel`）：`正式版`（stable，仅接收正式发布）或 `尝鲜版`（prerelease，提前接收预发布构建）。
- **镜像加速**（`settings.cn_mirror`）：开启后经 gh-proxy 镜像访问 GitHub Release，改善中国大陆下载速度；镜像地址（`settings.mirror_url`）可选预设或自定义，默认 `https://v4.gh-proxy.org`。

仅 NSIS 安装包支持应用内自动更新；便携版请手动下载新版本覆盖。详见[使用说明 · 更新](./usage.md)。
